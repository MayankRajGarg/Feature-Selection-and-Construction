# Feature Construction using K-Means Clustering

Implementing feature construction using K-Means Clustering to group similar features.

### Dataset
* This project uses the Diabetes dataset. 
* It has 442 samples with 10 numerical features. 
* The target variable(y) represents disease progression.

### Methodology

* Split the dataset into training and testing sets.
* Standardize the values for each feature.
* Apply K-Means clustering on the transposed training data to group similar features.
* Divide the 10 features into 5 clusters. (5 was best after testing)
* Construct new features by taking mean of features of each cluster.
* Train Linear Regression models using both original and constructed features.


### Evaluation Metrics

* Mean Squared Error (MSE)
* R² Score

### Output
* Feature groups generated by K-Means.
* Constructed features and reduced feature count.
* Performance comparison between original and constructed features.
* Results saved in `clustering_results.txt`.
